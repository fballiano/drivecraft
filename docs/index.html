Free and open source · macOS, Windows, and Linux · MIT or Apache 2.0

Why replace the official apps

Large companies make the official apps, and you cannot see their code. Each cloud also needs an app of its own. DriveCraft is one app for all your clouds.

Open source

Anyone can read the code and examine what the app does. Use it at no cost, under the MIT or Apache 2.0 license.

Private

No telemetry, no advertising, and no account with us. Your files go directly between your computer and your cloud. No server of ours is between them.

Light

A small, native app, written in Rust. It does not include a web browser, so it starts quickly and uses little memory.

How it works

DriveCraft keeps real copies of your cloud files in a folder on your computer, and syncs them in both directions.

Many clouds, many accounts

Each account syncs to a folder of its own in ~/DriveCraft, so the accounts never mix.

Selective sync

A switch for each folder: on, it syncs to this computer; off, it stays only online.

Real files

Your files are real copies on your disk, not placeholders. They open without a connection.

You choose first

After a sign-in, nothing downloads until you select the folders and start the first sync.

Safe by design

A missing folder stops the sync, so it cannot delete your files online. A file that changed on both sides keeps both versions.

A simple change

Unlink the official app, sign in to DriveCraft, and select your folders. DriveCraft downloads your files from the cloud.

Clouds

You sign in on the website of your cloud, in your browser. DriveCraft never sees your password.

Built on rclone

DriveCraft does not write a new sync engine. It puts a simple app on top of rclone, a tool that people trust with their files.

Tested for more than ten years

rclone is an open source tool for more than 70 cloud storage services. Many people and companies use it every day to move, sync, and back up their files.

rclone is included

Each package contains a tested version of rclone. The build verifies its SHA-256 checksum. DriveCraft uses its own rclone configuration, so it never changes your own rclone accounts.

One Rust code base

The same code makes the app for macOS, Windows, and Linux, on x64 and Arm processors. The window uses egui, a fast user interface library for Rust.

Install

macOS

macOS 11 or later. Signed and notarized by Apple.

brew tap fballiano/tap
brew trust --tap fballiano/tap
brew install --cask drivecraft

Windows

Download the zip file for x64 or Arm from the latest release. Extract it, and start DriveCraft.exe.

Linux

Download the tar.gz file for x64 or Arm from the latest release. Extract it, and start drivecraft.

Do you use the official app of your cloud now? Read Change from the official app before you start.
